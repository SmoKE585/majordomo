# TODO — заметки и будущие задачи

Раздел создан 2026-10-25. Здесь сохраняются обсуждения и требования до начала
реализации. Наличие заметки не означает, что функция уже работает или что
разрешено начинать её разработку.

## Порядок работы

- Одна тема — один Markdown-файл в `docs/todo/` с категорией `todo`
  и аудиторией `user, agent`. Добавляйте ссылку в список ниже.
- Фиксируйте дату, статус, цель, требования, ограничения совместимости,
  открытые вопросы и критерии готовности. Предложения отделяйте от решений.
- Начальный статус — «Запланировано». Для реализации создаётся отдельная
  задача со ссылкой на заметку и конкретным объёмом работ.
- Перед реализацией перечитайте актуальный код и правила проекта. Статус
  «В работе» ставьте после поручения реализации.
- После выполнения укажите статус «Выполнено», дату, результат и проверки.
  Невыполненные пункты и оставшиеся вопросы сохраняйте явно.
- Заметка не заменяет действующие инструкции агентам. Новые правила перехода
  становятся обязательными после внедрения соответствующего механизма.
