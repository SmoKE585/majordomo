# ИИ-агенты — план реализации

Дата согласования требований: 2026-10-23.

Это рабочий TODO для последовательной реализации готового решения. Этапы
задают порядок работы, а не сокращённый состав первой версии. Пункт отмечается
выполненным после реализации и проверки; рядом указываются результат и проверки.
Текущее состояние реализации и точка продолжения записаны в конце документа.

## Зафиксированные требования

- [x] Единственный интерфейс — существующая админка. Отдельную фронтенд-часть не создавать.
- [x] Использовать Neuron через Composer для общения с моделями и работы агентов.
- [x] В админке настраивать провайдеров, модели и произвольных агентов под разные задачи.
- [x] Поддержать OpenAI-совместимый Chat Completions API с настраиваемым адресом.
- [x] Создать двух стандартных агентов: помощника MajorDoMo и помощника редактора кода.
- [x] Оба агента могут объяснять и писать код; при недостатке данных задают уточняющие вопросы.
- [x] Помощник MajorDoMo использует документацию и Tools для изучения реальной установки.
- [x] Помощник редактора вставляет изменения в CodeMirror; штатное автосохранение сохраняет черновик/версию. Действующий метод или сценарий сохраняет сам пользователь.
- [x] Поддержка Qdrant входит в готовое решение, подключение сервиса опционально. Нужна отдельная настройка модели эмбеддингов.
- [x] Уточнение 2026-10-23: Qdrant может отсутствовать в стандартной поставке. Проверять настроенный API; без доступного сервиса выдавать подсказку и запрещать создание RAG-агентов. Обычные агенты используют текстовый поиск.
- [x] Уточнение 2026-10-23: возможность «Модель для эмбеддингов» выбирается у модели; несколько подходящих моделей используются по приоритету, при равенстве — по ID. Векторы разных моделей нельзя смешивать в одном индексе.
- [x] Источник знаний — существующие Markdown-файлы и документация установленных модулей.
- [x] Уточнение 2026-10-23: отдельного выключателя нет. Установленный модуль всегда доступен; готовность определяется наличием провайдера, модели и агента с моделью.
