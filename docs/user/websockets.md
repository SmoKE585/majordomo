# WebSocket — живые значения свойств

WebSocket отдаёт значения свойств и их изменения без постоянных HTTP-запросов.
Он работает только для чтения: запись, запуск методов и сценариев по WS запрещены.
Сервер проверяет очередь изменений раз в секунду, поэтому значения и события
могут приходить с задержкой примерно до секунды при обычной нагрузке.

## Подключение

Адрес — путь `/ws` на том же домене и порте, что админка, например
`wss://ваш-домен/ws`. Nginx направляет его во внутренний сервер ядра.
Отдельный внешний порт и настройки WebSocket не требуются; для HTTPS
шифрование обеспечивает nginx.

- В локальной сети ключ не нужен. Правила `HOME_NETWORK` совпадают с HTTP API.
- Извне нужен токен из раздела **API** панели. Передайте при подключении
  `Authorization: Bearer ВАШ_ТОКЕН` либо `X-API-Key: ВАШ_ТОКЕН`.
- Также подходит временный `access_token` из
  [входа пользователя](api.md#вход-пользователя), включая обычного пользователя.
  Ручной ключ для каждого внешнего интерфейса не нужен.
- Если библиотека не умеет заголовки, поддерживается `?token=ВАШ_ТОКЕН`.
  Используйте WSS и исключите такой URL из журналов.
- Админка подключается по своей сессии через короткий одноразовый билет.
  Общий постоянный пароль WebSocket больше не используется.

Отзыв или окончание срока API-токена закрывает уже открытое соединение при
ближайшей проверке, в пределах пяти секунд. Выход администратора и снятие прав
также закрывают соединение его сессии.

Пользовательский токен действует час без HTTP-запросов, максимум 12 часов.
WS-проверки, ping и получение свойств не продлевают этот срок. После истечения,
отзыва, смены пароля/логина или удаления пользователя соединение закрывается
с кодом `1008` и причиной `authorization_expired` в пределах пяти секунд.
Внешний интерфейс должен завершить свою авторизацию и показать вход;
HTTP API возвращает `401 token_expired` или `401 token_revoked` с
`error.details.reauthenticate=true`.

Браузер может подключаться с основного домена и любых его поддоменов.
Основа — настройка **Общие настройки → Публичный адрес** (`BASE_URL`):
для `https://siteA.example.com` разрешены `example.com`, `ui.example.com`
и остальные поддомены `example.com`. Посторонние домены запрещены даже
с действующим API-токеном. Если публичный адрес — IP или `localhost`,
разрешено только это имя/IP. Разрешённый домен не отменяет авторизацию извне.
Небраузерные клиенты без заголовка `Origin` проходят обычную проверку сети/токена.

## Какие данные приходят

Ничего запрашивать для подписки не нужно. После подключения сервер отправляет
`ready`, `snapshot_start`, пакеты `properties` и `snapshot_end`. Затем приходят
изменения всех свойств, включая свойства, созданные после подключения.
Снимок включает свойства без значения — у них `VALUE: null`.

Сообщение — JSON с полями `action` и `data`. Поле `data` само содержит JSON-строку:

```javascript
const response = JSON.parse(event.data);
if (response.action === 'properties') {
    const updates = JSON.parse(response.data);
    for (const item of updates) {
        // item.PROPERTY — например Room.temperature; item.VALUE — значение.
    }
}
```

Клиент может обновлять локальное состояние каждым пакетом. Дождитесь
`snapshot_end`, прежде чем считать начальную синхронизацию завершённой.
При переподключении очистите старое состояние на `snapshot_start` и примените
новый снимок: это также уберёт из вашей копии уже удалённые свойства.

Если нужны только будущие изменения, добавьте `?snapshot=0`. Для выборочной
подписки отправьте:

```json
{"action":"Subscribe","data":{"TYPE":"properties","PROPERTIES":["Room.temperature"],"REPLACE":true}}
```

Очередь может объединять промежуточные изменения одного свойства. Поток служит
для получения текущего состояния; для истории используйте журнал изменений.
После обрыва соединения требуется повторный снимок, воспроизведения всех
пропущенных событий нет.

## Обслуживание

Отдельный цикл `cycle_wscache` удалён. Очередь читает сам WebSocket-сервер ядра;
рестарта каждые шесть часов больше нет. Состояние видно в **X-Ray → Циклы** или
через `php majordomo cycles:status`. После изменения конфигурации перезапустите
`cycle_websockets` штатной кнопкой либо `php majordomo cycles:restart websockets`.

Nginx должен содержать маршрут /ws из [примера конфигурации](../deploy/nginx.conf.sample).
Подробности — [протокол WebSocket](../agents/websocket-ui-migration.md).
