# Режимы дома

Раздел **«Режимы»** находится в меню приложений: `/panel/modes.html`.
Режим — независимое состояние «включён / выключен». Например, одновременно
могут работать «Ночной» и «Эко». Постоянный код (`night`, `eco`, `away`)
используется в PHP и условиях других режимов; после создания он не меняется.

## Правила и внешние команды

Добавьте отдельные правила включения и выключения. Доступны три запуска:

- **В указанное время**: время и дни недели по часовому поясу системы.
- **При событии**: имя события MajorDoMo, например `NOBODY_HOME`.
- **Когда выполнятся условия**: сравнение свойства, состояние другого режима,
  интервал времени, в том числе через полночь.

В одном правиле можно потребовать все условия или хотя бы одно. Задержка
задаётся в секундах: `1800` — 30 минут. Для правила по условиям они должны
оставаться выполненными непрерывно; при нарушении ожидание отменяется.
Для события или расписания задержка начинается в момент запуска, а дополнительные
условия проверяются сразу и на протяжении ожидания. Новое одноимённое событие
начинает ожидание заново.

**Внешнее управление дополняет автоматику.** Если «Ночной» включился в 23:00,
а другой модуль выключил его в 23:10, он останется выключенным до следующего
срабатывания автоматического правила или новой внешней команды. Расписание
не отключается. Выполненное условие не повторяет команду каждую секунду:
для нового срабатывания оно должно сначала перестать выполняться и выполниться снова.
Повторная установка уже текущего состояния не запускает действия.

При совпадении правил включения и выключения состояние не меняется, а в карточке
появляется ошибка. Разведите их по времени или условиям. При сохранении формы
память неизменённых правил сохраняется.

Переключатель «Автоматические правила включены» приостанавливает только обработку
правил. Кнопки и PHP работают всегда. Ожидания используют сохранённые отметки времени
и продолжаются после перезапуска; при следующей проверке условия перепроверяются.
Расписание выполняется в указанную минуту. Пропущенные во время остановки системы
минуты не воспроизводятся задним числом. Во время остановки системы невозможно
подтвердить непрерывность условия: задержка будет отсчитываться заново после запуска цикла.

## Никого нет дома → охрана через 30 минут

1. Создайте режим «Никого нет дома», код `away`.
2. Создайте «Охрана», код `security`.
3. В охране добавьте правило «Включить режим / Когда выполнятся условия».
4. Добавьте условие «Другой режим → Никого нет дома → Включён».
5. Установите задержку `1800` секунд.
6. При необходимости добавьте второе правило: выключить охрану, когда `away` выключен.

Если `away` выключится до окончания задержки, охрана не включится.
Включение `away` можно связать с телефонами через условия их свойств
(«выполнены все»), либо вызвать из существующего модуля:

```php
enableMode('away', 'phones');
disableMode('away', 'phones');

if (isModeActive('security')) {
    // Дом под охраной.
}

setMode('eco', true, 'energy');
```

Функции доступны после стандартной загрузки MajorDoMo. Они принимают постоянный
код режима; неизвестный код вызывает исключение. `setMode`, `enableMode`,
`disableMode` возвращают `true`, если состояние изменилось, иначе `false`.
Состояние сразу видно другим модулям и условиям. Изменение публикует системное
событие `MODE_CHANGED` с полями `name`, `active`, `previous`, `source`, `details`.

## Действия и журнал

При включении и выключении можно вызвать метод, выбрать сценарий или написать
PHP-код без тегов. В PHP доступен массив `$mode` с контекстом перехода;
метод и сценарий получают тот же контекст в параметрах.

```php
if ($mode['active']) {
    cm('Alarm.arm');
}
```

Действия выполняются один раз на переход. Если действие завершилось ошибкой,
новое состояние сохраняется, ошибка появляется в карточке и журнале. Автоматического
повтора нет: код мог уже частично переключить реальные устройства. Журнал показывает
последние 100 переходов. Удалять можно только выключенные режимы, на которые
не ссылаются условия других режимов. Журнал при удалении сохраняется.

## Цикл и совместимость

Расписание и задержки обслуживает существующий цикл **Modes** (`cycle_states`).
Новые правила проверяются примерно раз в секунду. Старые объекты класса
`systemStates` продолжают получать вызовы `checkState` с прежним интервалом
около 11 секунд; переносить их в новый модуль необязательно. Список старых объектов
обновляется раз в минуту.

## Консоль

```bash
php majordomo modes:list
php majordomo modes:list --json
php majordomo modes:set away on
php majordomo modes:set away off --json
```

Команда переключения выполняет те же действия, что кнопка или PHP-функция,
и не отключает автоматику. При ошибке действия возвращается код завершения `1`;
фактическое состояние и текст ошибки доступны в JSON.
