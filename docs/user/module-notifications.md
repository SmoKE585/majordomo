# Уведомления модулей

Колокольчик возле профиля показывает число непрочитанных уведомлений всех
модулей. Если левое меню скрыто, он находится в шапке. На главной видны
первые пять сообщений; ошибки и предупреждения идут первыми.
Счётчик возле модуля открывает тот же центр с фильтром по модулю.

Открытие списка и переход в модуль ничего не отмечают прочитанным.
Нажмите «Прочитано» возле конкретного сообщения. Счётчики, главная и сообщения
в модуле обновятся вместе. Панель также обновляет список раз в минуту,
при возвращении во вкладку и кнопкой «Обновить» в центре уведомлений.

## Старые модули

Существующие вызовы не требуют изменений:

```php
$result = $this->sendNotification('Нет связи с устройством', 'warning');
$result = $this->readNotification($notificationId);
```

Оба метода по-прежнему возвращают JSON. Уровни: `default`, `info`, `success`,
`warning`, `danger`. Прочтение принимает целочисленный ID или текст сообщения
и касается только своего модуля.

Пока запись не прочитана, отправка того же текста и уровня тем же модулем
полностью отбрасывается: нет новой записи, изменения даты, счётчика повторов
или строки в логе. Ответ сохраняет прежние `status=false`, `error` и `id`
существующей записи. Проверка защищена MySQL advisory lock от параллельных
отправок. После прочтения сообщение может появиться снова.

Сохранён прежний предохранитель: если у модуля уже больше десяти непрочитанных
уведомлений, новые отклоняются. Повтор проверяется до этого лимита.
Поле `MESSAGE` вмещает 255 символов после удаления HTML и экранирования.
Для длинного объяснения используйте `details`.

## Расширенные сообщения

Сервис ядра возвращает массив с теми же полями результата:

```php
use MajorDoMo\Core\Core;

$result = Core::notifications()->send($this->name, 'Требуется повторный вход', 'warning', array(
    'key' => 'account.authorization',
    'title' => 'Авторизация истекла',
    'details' => 'Откройте настройки модуля и снова войдите в учётную запись.',
    'url' => ROOTHTML . 'panel/tuya.html',
    'label' => 'Открыть настройки',
));
```

| Поле | Назначение | Максимум символов |
| --- | --- | --- |
| `key` | Стабильный ключ события внутри модуля | 190 |
| `title` | Заголовок | 200 |
| `details` | Раскрываемые подробности, обычный текст | 16000 |
| `url` | Внутренний абсолютный путь, например `/panel/tuya.html` | 2048 |
| `label` | Подпись перехода | 100 |

С ключом повтор определяется модулем и ключом независимо от текста и уровня.
Непрочитанная запись не обновляется: первые текст и подробности сохраняются
до прочтения. Не включайте меняющиеся даты или значения в ключ.
Без ключа действует проверка по модулю, тексту и уровню.

Подробности отображаются текстом, без исполнения HTML. Разрешены только
внутренние ссылки. Для закрытия устранённой проблемы модуль может вызвать
`Core::notifications()->readLegacy($this->name, (int)$notificationId)`;
подойдёт также ID из ответа на повтор.

Поля добавляет файловая миграция `20261025_module_notifications` при штатном
обновлении. До неё старые вызовы и интерфейс продолжают работать; расширенные
поля возвращают явную ошибку о необходимости миграции.

## Контракт панели

`GET /api/v1/panel/notifications?module=tuya&offset=0` возвращает `items`, `total`,
`counts`, `levels`, `severity`, `offset`. Фильтр необязателен; страница содержит
до 50 записей. `counts` и `levels` — общие счётчики, `total` и `severity`
относятся к выбранному фильтру.

`POST /api/v1/panel/notifications/dismiss` принимает прежние `id` или `module`.
Оба маршрута требуют сеанс администратора; изменение проходит штатную
CSRF-проверку. Старые AJAX-адаптеры панели сохранены.
