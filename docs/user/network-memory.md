# Память MQTT и WebSocket

Настройки задаются в `.env`; значения по умолчанию уже действуют без изменения
рабочего файла. Новые параметры читает `MajorDoMo\Core\Config`.
Работающие циклы подхватывают изменения после перезапуска.

## MQTT

| Параметр | По умолчанию | Назначение |
| --- | --- | --- |
| `MQTT_MAX_PACKET_BYTES` | `1048576` | Максимум байт тела входящего пакета, включая заголовок топика. |
| `MQTT_PACKET_TIMEOUT` | `5` | Срок получения полного пакета и таймаут чтения/записи сокета, секунды. |

Обычные сообщения Zigbee2MQTT обрабатываются сразу при готовности сокета,
без фиксированной паузы после проверки входящих данных. Неполный пакет
возвращает управление циклу, чтобы продолжали работать heartbeat и исходящая
очередь. При истечении срока соединение закрывается; цикл повторяет подключение.

Превышающий лимит пакет QoS 0 пропускается порциями до 8 КиБ, с записью в
`errors.log`. Следующие сообщения сохраняют порядок и продолжают обрабатываться.
Для слишком большого пакета, требующего подтверждения, соединение закрывается
с ошибкой. Предел можно увеличить для крупных служебных сообщений Zigbee2MQTT.
Обычные показания датчиков и команды ограничением частоты не затрагиваются.

Подтверждения подписок и retained-сообщения обрабатываются общим приёмником,
чтобы несколько подписок подряд не приводили к потере сообщения.

## WebSocket

| Параметр | По умолчанию | Назначение |
| --- | --- | --- |
| `WEBSOCKETS_CACHE_MAX_ENTRIES` | `4096` | Максимум значений в кэше. |
| `WEBSOCKETS_CACHE_MAX_BYTES` | `8388608` | Суммарный размер ключей и значений; для массивов учитывается JSON. |
| `WEBSOCKETS_CACHE_TTL` | `300` | Время хранения значения, секунды. |
| `WEBSOCKETS_MAX_SUBSCRIPTIONS` | `4096` | Суммарный предел подписок одного клиента. |

Все значения должны быть положительными. При заполнении кэша вытесняются давно
неиспользуемые записи. Просроченные значения удаляются; при чтении отсутствующего
значения используется `getGlobal()`. Значение, которое слишком велико для кэша,
продолжает передаваться подключённым клиентам без сохранения в кэше.

Подписка `TYPE: objects` заменяет прежний список объектов. Старые подписки на
свойства и события остаются добавочными. Новый клиент может передать
`REPLACE: true` в `Subscribe`, чтобы заменить подписки только указанного типа,
либо отправить `Unsubscribe` с тем же `TYPE` и списком `PROPERTIES`/`EVENTS`.
Без списка снимаются все подписки этого типа. Превышение предела отклоняется
целиком и пишется в `errors.log`; прежние подписки сохраняются.

Админка снимает подписку страницы объекта и удаляет её обработчики событий
при замене содержимого через `partLoad`.

## Локальные проверки

`php tests/network_memory_smoke.php` проверяет настоящий MQTT-приёмник на
loopback-сокетах и приложение WebSocket с подменой хранения. Рабочие БД,
Redis и MQTT-брокер не используются. В том числе проверяются 30 000 сообщений,
неполные и слишком большие пакеты, порядок доставки, кэш и замена подписок.

`node tests/websocket_subscriptions_smoke.mjs` проверяет 100 смен страниц,
повторное подключение и удаление обработчиков страницы без запуска приложения.
