# Провайдеры и модели

Модуль работает с OpenAI-совместимым протоколом Chat Completions. Один
провайдер — это адрес API и таймаут; модели у него могут быть разные, каждая
со своим токеном и возможностями.

## Провайдер

Откройте «ИИ-помощник» → «Провайдеры» → «Добавить провайдера».

- **Название** — произвольное, видно только в админке.
- **Базовый URL** — корень API без `/chat/completions`, например
  `https://api.openai.com/v1` или `http://127.0.0.1:11434/v1`.
- **Протокол** — сейчас только OpenAI Chat Completions.
- **Таймаут** — общий предел ожидания ответа API.

Локальные адреса разрешены. Перенаправления (HTTP 3xx) запрещены: укажите
конечный адрес API. Логин и пароль в URL не поддерживаются.

## Модель

В карточке модели укажите точный идентификатор, который принимает API
(`gpt-4o-mini`, имя локальной модели и т. п.). Отображаемое название может быть
любым.

Возможности включаются галочками:

- **Чат** — обычный диалог;
- **Вызов инструментов** — модель умеет запрашивать Tools; без этого агент
  с инструментами работать не будет;
- **Эмбеддинги** — модель векторизует тексты для RAG. У таких моделей есть
  приоритет: меньшее число используется раньше.

Параметры `temperature` и `top_p` необязательны. Пустое поле означает значение
провайдера. Ограничения контекста и ответа задаются в токенах.

## Токен

Токен шифруется AES-256-GCM и хранится в БД только шифротекстом. В браузер,
историю чата и ответы модели он не попадает. При редактировании:

- пустое поле сохраняет прежний токен;
- галочка «Очистить сохранённый токен» удаляет его;
- смена адреса Qdrant требует заново задать ключ Qdrant (это отдельная
  настройка базы знаний).

Ключ шифрования берётся из `AI_SECRET_KEY` (32 случайных байта в base64) или
создаётся в `var/ai_assistant/secret.key` с правами 0600. Сохраните ключ
отдельно от БД: без него токены не восстановить. Модуль не меняет `.env`
автоматически.

## Проверка

Кнопка «Проверить соединение» в списке моделей или в карточке модели делает
короткий запрос:

- для чата — просит ответить `OK`;
- для Tools — просит вызвать тестовый инструмент;
- для эмбеддингов — получает вектор и показывает размерность.

Проверка не отправляет данные дома и не выполняет запрошенные инструменты.
Ошибки показываются по-русски: неверный токен, неизвестная модель, лимит,
таймаут, ошибка сервера.

## Если модель не используется

Модель, назначенная агенту или выбранная для индекса знаний, нельзя удалить,
пока связь не снята. Так агент не останется с неработающей ссылкой. Выключение
провайдера или модели блокирует только те функции, где они нужны; остальная
админка продолжает работать.

## Ограничения

- Провайдеры с нестандартным протоколом (не OpenAI Chat Completions) пока не
  поддерживаются.
- Реальный внешний провайдер в автоматических тестах не вызывается: тесты
  используют локальную имитацию и FakeAIProvider.
