# Чат и история

Чат открывается в разделе «ИИ-помощник». Отдельного включения нет: если у
включённого агента есть модель, чат готов к работе.

## Диалоги

- «Новый» создаёт диалог с выбранным агентом.
- Диалоги принадлежат администратору: чужой диалог нельзя открыть или
  продолжить подстановкой ID.
- Удаление убирает диалог из списка и останавливает активную генерацию.
  Сообщения сохраняются в БД для истории, но недоступны через интерфейс.
- Название диалога обновляется по первому вопросу, если оно ещё стандартное.

История хранится в собственных таблицах модуля. Для каждого сообщения
сохраняются роль, текст, время и служебные метаданные: использованные
инструменты, источники, расход токенов и причина завершения.

## Ответ

Ответ приходит потоком. Во время генерации видно:

- текст по мере поступления;
- текущий инструмент и его завершение;
- кнопку «Остановить».

Остановка прекращает поток и сохраняет уже полученный текст как неполный ответ.
Повторная отправка создаёт новый запуск; уже выполненные действия инструментов
не повторяются.

Если провайдер вернул ошибку, в диалоге появится понятное сообщение: токен,
модель, лимит, таймаут, сеть или формат ответа. Токен и тело ответа API в
сообщение не попадают.

## Источники

Под ответом показываются ссылки на статьи базы знаний, объекты, свойства,
методы и сценарии, которые вернули инструменты. Ссылки ведут в админку и
открываются в новой вкладке. Это проверяемые данные, а не цитаты модели.

## Что видит модель

В контекст передаются:

- инструкции агента;
- предыдущие сообщения диалога в пределах контекста модели;
- результаты разрешённых инструментов;
- контекст редактора, если диалог создан из редактора.

Не передаются: токены, ключи, cookie, файлы `.env`, произвольные файлы
установки. Справочные данные очищаются от распознаваемых секретов.

## Ограничения

- Один диалог — одна активная генерация. Параллельная отправка блокируется.
- Лимит запроса — 16 000 символов; история обрезается по контексту модели.
- Если модель не поддерживает Tools, агент с инструментами не запустится:
  выберите другую модель или снимите инструменты.
- Ответ модели может быть неполным. Имена, код и результаты проверяйте по
  ссылкам и реальной установке.
