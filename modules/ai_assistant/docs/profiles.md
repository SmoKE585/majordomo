# Агенты и инструменты

Агент — это инструкции, модель, набор инструментов и источники знаний.
Инструкции задают стиль и порядок работы, но не дают новых прав: сервер
проверяет разрешения на каждом вызове.

## Стандартные профили

При установке создаются два агента:

- **Помощник MajorDoMo** — объясняет систему, ищет объекты, свойства,
  обработчики, связи и код.
- **Помощник редактора** — работает с текущим черновиком метода или сценария,
  учитывает код родителя и не сохраняет форму.

Оба профиля можно менять и копировать. Кнопка «Восстановить стандартные
инструкции» заменяет только текст инструкций, сохраняя выбранную модель и
остальные настройки. Обновление модуля не перезаписывает пользовательский текст.

## Свой агент

Создайте агента, выберите модель с чатом (и с Tools, если включаете
инструменты), задайте инструкции и лимиты:

- **Лимит шагов** — сколько шагов и вызовов инструментов разрешено за один
  ответ; максимум 32;
- **Таймаут** — предел времени на запуск.

Выключенный агент не запускается, но остаётся в списке. Удаление убирает его из
выбора и освобождает модель; история диалогов сохраняется.

## Инструменты

Доступны только чтение и поиск:

| Инструмент | Что делает |
| --- | --- |
| `find_objects` | Ищет объекты по имени, классу, описанию |
| `read_object` | Показывает класс, наследование, свойства и методы |
| `read_property` | Значение, обработчик, история, связанные модули |
| `find_references` | События, привязки модулей и текстовые совпадения в коде |
| `read_code` | Код метода объекта/класса или сценария, код родителя |
| `read_history` | Последние изменения свойства из журнала аудита |
| `find_scripts` | Поиск сценариев по названию, описанию и коду |
| `search_knowledge` | Поиск по Markdown-документации |
| `read_knowledge` | Чтение статьи порциями |

Модель не получает произвольный SQL, shell, запуск PHP или запись в системные
таблицы. Инструменты возвращают ограниченные страницы и ссылки в админку.
Текстовые совпадения явно отделены от точных привязок: динамически собранные
имена могут не найтись, и это не доказывает отсутствие связи.

## Источники знаний

- **Документация ядра** — `docs/**/*.md`.
- **Документация установленных модулей** — `modules/<name>/docs/**` и README.

Источники выбираются у агента. Удалённый модуль исчезает из поиска.

## Режим знаний

- **Текстовый поиск** — работает без Qdrant, ищет по словам и заголовкам.
- **RAG** — смысловой поиск по готовому индексу Qdrant. Требует доступного
  Qdrant, включённой модели эмбеддингов и собранного индекса. Если сервис
  недоступен, сервер не подменяет RAG текстовым поиском молча.

Агента можно перевести обратно на текстовый поиск даже при недоступном Qdrant.

## Безопасность

- Результаты инструментов и документы считаются данными, а не инструкциями.
- Токены, пароли и приватные ключи вырезаются из справочных данных до отправки.
- Права проверяются по сессии администратора, агенту и модулю при каждом
  вызове; отмена запроса также проверяется.
- Ошибки инструмента не раскрывают тело ответа провайдера или секреты.
