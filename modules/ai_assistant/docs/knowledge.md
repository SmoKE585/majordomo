# База знаний и Qdrant

Источник знаний — существующие Markdown-файлы: `docs/**/*.md` и документация
установленных модулей. Отдельной копии документов модуль не создаёт.

## Два режима

- **Текстовый поиск** — всегда доступен, не требует внешних сервисов. Ищет по
  заголовкам, описанию и тексту статей.
- **RAG** — смысловой поиск по индексу Qdrant. Нужны доступный Qdrant,
  включённая модель эмбеддингов и собранный индекс.

Режим выбирается у агента. Если Qdrant недоступен, RAG-агент не запускается;
текстовый поиск при этом продолжает работать. Скрытой подмены одного режима
другим нет.

## Подключение Qdrant

Qdrant не входит в стандартную поставку. Установите его отдельно или подключите
на другом сервере. В разделе «База знаний» укажите:

- адрес HTTP API (например, `http://127.0.0.1:6333`);
- API-ключ, если сервер его требует;
- таймаут.

Кнопка проверки читает только список коллекций. Документы при диагностике не
передаются. Коллекции создаются автоматически при первой сборке.

## Модель эмбеддингов

Создайте модель с возможностью «Эмбеддинги» и отметьте её в параметрах индекса.
Можно настроить порядок: меньшее значение приоритета используется раньше.
Выключенные модели и провайдеры исключаются.

Векторы разных моделей несовместимы. Для каждой модели — своя коллекция и своя
размерность; смешивать их в одном индексе нельзя.

## Сборка индекса

1. Сохраните параметры: модель, размер фрагмента, перекрытие, число фрагментов
   в ответе и предел контекста.
2. Нажмите «Собрать» у нужной модели.
3. Дождитесь завершения. Прогресс показывается в карточке.

Сборка идёт порциями из админки. Новый индекс пишется в отдельную коллекцию;
рабочий переключается только после успешного завершения. Если сборка
прервалась, старый индекс продолжает обслуживать поиск.

Изменение модели или параметров разбиения требует новой сборки. Повторная
сборка заменяет индекс целиком, поэтому дублей и устаревших документов не
остаётся.

## CLI

```bash
php majordomo ai:index --model=1
php majordomo ai:index --all --json
php majordomo ai:rag-check --json
```

`ai:index` собирает индекс по шагам и не раскрывает токены. `ai:rag-check`
проверяет доступность Qdrant и наличие модели эмбеддингов, но не создаёт
коллекции и не проверяет актуальность индекса.

## Ограничения

- Для общей установки Qdrant точки разделяются ключом установки, а поиск
  фильтруется по источнику (`core`/`modules`).
- Удаление рабочего индекса заблокировано: сначала соберите новый.
- Автоматические тесты используют имитацию Qdrant; реальный сервис нужно
  проверить отдельно.
- При недоступном Qdrant показывается причина, а не «успешный» пустой ответ.
