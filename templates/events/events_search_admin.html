API

Как вызвать событие

Из сценария, метода объекта или внешнего запроса.

PHP
registerEvent('path/to/event', array(
    'param1' => 'value1'
));
HTTP API
GET /api/events/path/to/event
    ?param1=value1

Повторный вызов обновляет запись события и его параметры, поэтому в таблице один путь = одна строка.
